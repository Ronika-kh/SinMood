# SinMood | سین مود 🎬

## درباره پروژه

سین مود یک وب‌سایت پیشنهاد فیلم بر اساس حس‌وحال کاربر است. در این سایت، کاربران می‌توانند فیلم‌های مختلف را مشاهده کنند و با توجه به حال و احساس خود، فیلم مناسب‌تری برای تماشا پیدا کنند.

هدف سین مود، ساده‌تر کردن انتخاب فیلم و ایجاد تجربه‌ای جذاب‌تر برای کاربران است.

## بخش‌های سایت

- صفحه‌ی اصلی
- پیشنهاد فیلم
- نمایش همه‌ی فیلم‌ها
- جزئیات فیلم‌ها
- درباره ما
- جست‌وجو
- ورود و ثبت‌نام

## امکانات

- نمایش مجموعه‌ای از فیلم‌ها
- مشاهده‌ی اطلاعات و جزئیات هر فیلم
- نمایش جزئیات فیلم در پنجره‌ی Modal
- طراحی واکنش‌گرا برای اندازه‌های مختلف صفحه‌نمایش

## تکنولوژی‌های استفاده‌شده

- HTML
- CSS

## نحوه‌ی اجرا

فایل `index.html` را در مرورگر باز کنید تا سایت اجرا شود.
